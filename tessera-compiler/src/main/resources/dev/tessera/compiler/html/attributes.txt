# Attribute names a computed attribute (t:<name> or a t:attr entry) may have (#330,
# docs/security-architecture.md section 5.6, docs/context-model.md section 6.2), besides data-*,
# plain [a-z][a-z0-9]* names on a custom element, and the framework names Contexts classifies.
# Contexts.attribute still classifies each name (URL, STYLE, FORBIDDEN, ...); this file only
# says which names exist. Static attributes are not checked against it.
#
# One lower-case name per line, sorted, then the sources it comes from:
#   html           WHATWG HTML Living Standard (26 October 2026), indices.html, table
#                  "List of attributes (excluding event handler content attributes)"
#   html-obsolete  same, obsolete.html section 16 (element-attr definitions), and the font
#                  element's face from rendering.html section 15.3
#   svg            SVG 2 (W3C Candidate Recommendation 04 October 2018), attindex.html (regular
#                  and presentation attributes, including those it links to SVG Animations and
#                  Filter Effects) and propidx.html, plus d (paths.html), missing from the index
#   mathml         MathML Core (W3C Candidate Recommendation Snapshot 24 June 2025), attribute
#                  definitions
#   aria           WAI-ARIA 1.2 (W3C Recommendation 06 June 2023), states and properties, plus role
# Event handlers (on*) are left out: Contexts makes every on* name EVENT_HANDLER, a build error.
