# The inert-text attributes (#539): the standard attributes (attributes.txt) whose
# computed value may be a plain value (String, number, enum, ...), escaped as an ordinary attribute.
# Every other standard name gets a specific context from Contexts.attribute (URL, RESOURCE_URL,
# STYLE, REFRESH, FORBIDDEN, ...) or is TYPED_ATTRIBUTE: its value may only combine string
# literals and numbers (#565).
# Names that are not standard (data-*, a custom element's own attributes, framework names such as
# hx-*) are not listed: Contexts.attribute makes every one NEUTRAL. A listed name that is also a
# tree-builder input on some element (type on <input> and <script>, Contexts.isTreeBuilderInput)
# is FORBIDDEN there before this file is asked.
#
# Format: one lower-case name per line, sorted, then its group, and, optionally, the only HTML
# elements it is inert on (comma-separated). Only HTML elements are listed: every attribute of an
# SVG or MathML element is FORBIDDEN (#678). for is an ID reference
# on <label> and <output>, but on <template> the spec's "Text" moves the content (#419); value is
# inert on form controls and <data>, <li>, <meter>, <progress>, but not on <param>, where a browser
# may read a src, movie, code or url parameter as the <object>'s resource URL.
#
# Rule. A name is inert when the value type of every definition of the name in HTML is one of
#   Text, an enumerated keyword, a number / integer / date or time, a boolean attribute, an ID or a
#   set of ID references, a BCP 47 language tag, or a set of space-separated tokens,
# and none of those definitions lets the value change what the browser fetches, submits, navigates
# to, runs, grants (permissions, sandbox, CSP) or how it parses the page. Sources:
#   HTML  WHATWG HTML Living Standard (30 October 2026), indices.html, "List of attributes (excluding
#         event handler content attributes)", column "Value"; obsolete.html for html-obsolete names.
#   ARIA  WAI-ARIA 1.2 (W3C Recommendation 06 June 2023), section 6.6 value types: true/false,
#         tristate, true/false/undefined, ID reference (list), integer, number, string, token (list).
#
# Groups:
#   text      HTML value type "Text" (alt, title, placeholder, value, ...)
#   keyword   HTML enumerated attribute (dir, autocomplete, contenteditable, type, ...)
#   number    HTML valid integer / floating-point number / date-time string (colspan, max, ...)
#   boolean   HTML boolean attribute (checked, disabled, ...); allowfullscreen is left out (a permission)
#   idref     HTML ID / set of space-separated IDs (for, form, list, headers, ...)
#   tokens    HTML set of space-separated tokens without URLs (class, accesskey), language tags,
#             media queries and source size lists (they select among already-checked URLs)
#   obsolete  html-obsolete presentational attributes (colours in the legacy colour syntax, lengths,
#             keywords and text: bgcolor, border, align, ...)
#   aria      every WAI-ARIA 1.2 state and property, and role
#
# Left out on purpose (HTML; each has a specific context already or becomes TYPED_ATTRIBUTE):
#   URL types: action, cite, data, formaction, href, itemid, itemprop, itemtype, manifest, ping,
#     poster, src, srcset, imagesrcset, usemap, background, classid, codebase, archive, longdesc,
#     lowsrc, profile, datasrc, urn
#   fetch / submit / navigate: accept-charset, as, blocking, crossorigin, decoding, enctype,
#     fetchpriority, formenctype, formtarget, integrity, loading, preload, referrerpolicy, rel,
#     target
#   grants or decides: allow, allowfullscreen, sandbox, color (but on <font> and <hr>; on <link> a CSS colour), charset, http-equiv,
#     is, srcdoc, style, shadowroot*, language (script), code, codetype, declare, event, datafld,
#     dataformatas, datapagesize, methods, scheme, standby, typemustmatch, version, rev, nohref,
#     contextmenu, dropzone, allowtransparency
# Kept on purpose: name (also <meta name>), type (not <input> or <script>, see above), nonce
#   (CSP; it can only allow the template's own static script), pattern (a regular expression the
#   browser only matches input against), command, method and formmethod (GenericAttrProcessor
#   rejects a computed method on a <form> and a computed formmethod at build time).
# content is listed for <meta> only, and Contexts narrows it further (#590): it is inert only on a
#   <meta> whose static name is on an allow-list (description, keywords, author, application-name,
#   generator, color-scheme, theme-color), with no http-equiv, property or itemprop and no computed
#   name. Elsewhere on <meta> it is REFRESH (http-equiv=refresh), FORBIDDEN (http-equiv=Content-Type)
#   or TYPED_ATTRIBUTE (another http-equiv, a policy such as referrer or viewport, a name a browser,
#   OS or crawler acts on such as apple-itunes-app, an unknown name, Open Graph, or no static name).
