# The review probes of Oct 24 (memo §5.1, research-systemic tv/probes.txt) and the two templates of
# the #351 table finding, with what #367 expects. A body is wrapped in <div t:params="String s">
# unless its first tag declares t:params.
#   VERIFIER     the verifier alone rejects it (the profile's diagnostics suppressed)
#   PROFILE      the profile's tokenizer rejects it; the compiler builds no tree to verify
#   ACCEPT       the verifier accepts it, and it compiles (unless a "# profile:" line says the
#                profile rejects it first)
#   NOT_COVERED  outside markup contexts (families D, E); not asserted
====
# name: T1-text-in-tbody
# expect: VERIFIER
<table><tr><td>a</td></tr>[[s]]</table>
====
# name: T2-text-before-row
# expect: VERIFIER
<table>[[s]]<tr><td>a</td></tr></table>
====
# name: T3-ttext-in-tr
# expect: VERIFIER
<table><tr><td>a</td><t:block t:text="s"></t:block></tr></table>
====
# name: T4-tr-inside-td
# expect: VERIFIER
<table><tr><td><table><tr><td>x</td></tr></table><tr><td>y</td></tr>[[s]]</td></tr></table>
====

====
