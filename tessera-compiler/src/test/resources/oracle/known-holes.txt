# Known open holes for the Node job (#322, node/check.mjs).
#
# One hole per line:
#
#   <case-id> <KIND> <engine or *> #<issue> <note>
#
#   case-id  first 12 hex chars of the SHA-256 of the case's template (OracleCase.idOf)
#   KIND     a family C, D or E kind, the value checks the build-time verifier (#367) doesn't
#            cover: JS_NOT_LITERAL, JS_UNPARSABLE, LIVE_SCRIPT (inside an HTML script's data only)
#            (C, script lexical position), JS_URL, CROSS_ORIGIN_RESOURCE (E, URL policy); or
#            ENGINE_DRIFT (#399: an engine builds a tree for an accepted render that the vnu engine
#            doesn't build), for one Node engine, never *. A family A/B finding (STRUCTURE_CHANGED,
#            MARKER_IN_NAME, LIVE_HANDLER, CONTEXT_MISMATCH) on a template the verifier accepted is
#            a verifier soundness bug, fixed in the verifier, never listed.
#   engine   parse5, chromium, firefox, webkit, or * for any engine
#   #issue   the issue that fixes it (required: a line without one is a format error)
#   note     free text: the seed name
#
# A finding with no line here fails the job; a line for an engine the job ran whose finding no
# longer occurs fails too ("delete its line"), so this list only shrinks. Lines starting with #
# are comments.
