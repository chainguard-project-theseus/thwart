# EWP Registry Service: every reachable template and form state, and the error responses.
#
# start.sh serves the manifests in manifests/ over local HTTPS and opens port 8080 only once every
# source in manifest-sources.xml has been fetched, so every page sees the same catalogue:
# example.xml (University of Warsaw, echo API with HTTP security), vienna.xml (University of
# Vienna, imports cleanly), krakow.xml (Jagiellonian University, a name with markup characters),
# overview-1.xml and overview-2.xml (both cover Test 3: duplicates in the overview), registry.xml
# (the registry's own manifest imported by someone else: its Registry API entry is dropped),
# invalid.xml (an API entry with an unknown schema), missing.xml (a 404) and vienna.xml again
# behind a hei-regex that filters its HEI out.
#
# Pages show two things that change between runs and are ignored in app.json: the time each
# manifest was last fetched with its PrettyTime suffix ("(moments ago)"), and the commit and
# build day in the home page's version line.
#
# The /validate requests are the JSON that the schema validator page's script fetches. Error
# responses (404, 500) are XML documents from RegistryErrorController, not templates.
#
# Unreachable: validationResult.peb renders the API validator's result, but /validateApi takes a
# JSON request body (the recorder posts forms only) and runs live tests against the API's remote
# URL. The manifestValidation page that hosts the validator form (a Vue component) is recorded.
