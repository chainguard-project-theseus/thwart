# ESPD-Service (espd-web): JSP pages composed with Apache Tiles 3 definitions (tiles.xml), under
# /espd. No database: the wizard keeps the ESPD document in the session (@SessionAttributes), so
# the requests run in order as one browser session. Validation is client-side; the server-side
# "invalid" states are binding errors: a step's "previous" button re-renders the step with them
# (selection shows them in <form:errors path="*">), and a "next" with one is a 400 error page.
# The contracting authority's steps bind no typed field, so they have no invalid state.
# The clock is pinned to 2025-06-15 (start.sh): the turnover years and the current year depend
# on it. Not covered: the XML/PDF/ZIP downloads (files, not pages, with generated IDs and times),
# the upload actions on /filter (the crawler sends no multipart bodies), 500.jsp (only the
# WebLogic web.xml maps it) and criteriaTemplates/requestCriterion.jsp (no page includes it).
