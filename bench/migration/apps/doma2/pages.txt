# doma2 (sample-web-admin, context path /admin): login (failure, success), the password reset and
# change pages, and for each master (users, staffs, holidays, codes, code categories, roles) the
# list with and without search criteria, the new and edit forms invalid and valid, the detail page
# and removal, and the error pages (404 and 500). Requests run in order against a
# fresh in-memory H2 loaded by Flyway (start.sh), clock at 2025-06-15 10:00 JST.
#
# Each form carries a random _double (double-submit) token: ignored in app.json. pages.txt doesn't
# send it back, and the app checks it only when it is sent. Invalid posts redirect back to the
# form, which shows the errors from flash attributes.
#
# Not here: /admin/mailTemplates/* and /admin/uploadFiles/list answer 500 in the original, because
# the controllers name modules/mailTemplate/... and modules/uploadFile/... but the template
# directories are lower case (it works only on a case-insensitive file system); their four
# templates are not rendered. The app's own exception handler names its error views
# /error/404.html, /error/403.html and /error/500.html, which don't resolve, so a missing record
# or a role without a permission gets Boot's error page with status 500 (one such page is here:
# /admin/users/show/abc). For the same reason error/403.html is never rendered: access denied
# redirects to /forbidden, whose view name is /error/403.html too. CSV, Excel and PDF downloads are not HTML. File uploads are multipart.
