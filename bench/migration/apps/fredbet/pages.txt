# fredbet: every reachable template, anonymous and logged in (admin, plain users, a child user),
# each form in its invalid and valid states, and the error pages. Requests run in order against a
# fresh in-memory H2 database that holds only the admin user (admin/admin) at startup.
#
# All data comes from explicit form posts, never from the random demo-data generators
# (/administration/testdata, createDemoBets, createDemoResults, /bet/dice). Kickoff dates are
# absolute: matches are created in 2099 so they can be bet on, then three are moved to 2020 and
# given results. "Today", "yesterday" and the top-tipper-of-today badge are therefore empty.
#
# IDs follow from the order below: users 1 admin, 2 anna, 3 ben (child), 4 O'Hara<b>, 5 temp
# (deleted), 6 dora (self-registered, renamed dorothy); matches 1-6 plus 7 (deleted); image
# groups 1 Users (profile images, not deletable), 2 Holidays, 3 Temp (deleted).
