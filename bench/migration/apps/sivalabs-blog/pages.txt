# sivalabs-blog: every template, anonymous and logged in (admin, then a new author), and both
# states of every form a browser posts without script. Requests run in order against a fresh
# PostgreSQL with Flyway's seed (users, categories, tags, settings) plus flyway/V100__bench_seed.sql
# (posts in every status, comments, subscribers, a message, page views); clock at 2025-06-15 10:00.
#
# Not here: the htmx endpoints (hx-delete/hx-put on /admin/posts, /admin/comments, /admin/tags,
# /admin/messages, /admin/subscribers and hx-post /newsletter/subscribe). They are matched only
# with an HX-Request header, which pages.txt can't send, and they render no template (an
# HX-Refresh or a plain string). The profile image upload is multipart. index.html is never
# rendered: / redirects to /posts. Error pages: 404 (a missing post), 500 (bad parameters, and an
# unknown path, which the app's catch-all exception handler answers) and 403 (the author on
# /admin/users).
