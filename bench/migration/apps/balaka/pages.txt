# balaka: every template as admin (admin/admin, MFA off), then as the employee login (self-service
# pages and a 403). Fresh PostgreSQL per start: the integration-test seed plus seed/ (vendor, bill,
# assets, amortization, bank statement and reconciliation, contract, fiscal periods, BOM,
# production order, recurring transaction, tax case and archive, withholding payment, alerts), all
# with fixed ids; clock at 2025-06-15 (start.sh).
#
# Forms: each form is posted blank or with a bad value (the invalid state), then valid. A valid post
# that creates a record with a random id (assets, products, accounts, users and the other
# UUID-keyed records) would put that id in URLs and links, so those forms are posted valid as an
# edit of a seeded record instead. Records keyed by a code (clients, vendors, employees, projects,
# invoices) are also created, last, since later forms would list their random ids. Two forms
# have no invalid state: recurring create (blank fields answer 500, no validation) and the
# self-service profile (no validation); alert thresholds, tax profile and evidence posting policy
# have none either. Invalid only, since a valid post creates a random-id row and there is no
# seeded record to edit instead (or its edit form is built by script): bank reconciliation,
# fiscal period (closing a seeded month stands in), inventory purchase/sale/adjustment, payroll
# run, journal template, tax case, evidence requirement, API client, fiscal adjustment and
# withholding payment.
#
# htmx: the partial endpoints are requested directly (dashboard widgets, quick transaction,
# template search and preview, tax-detail section, stock and transaction tables, disposal preview,
# entry table, favourite button, template tags). List endpoints that answer a partial only with an
# HX-Request header are covered by their full page, which includes the same fragment.
#
# Not covered: layouts/print (no page uses it), mfa-verify (MFA is off), setup (the setup wizard is
# off). Left out: PDF/Excel/CSV exports, JSON APIs, file uploads (bank statement and archive
# import, logo, documents), and posts that create rows with random ids shown on later pages
# (posting transactions, payroll runs, disposals, depreciation runs, fiscal closing, API clients).
# /forgot-password and /reset-password answer 503 because password reset (mail) is not
# configured. The tag form with an unknown tag type answers 500 (the app's JSON error handler
# cannot answer text/html) and the reconciliation form without a statement answers 400.
