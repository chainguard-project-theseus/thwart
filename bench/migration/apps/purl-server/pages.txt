# purl_server: every reachable template, anonymous and logged in (admin, and user1 without the
# admin role), each form in its invalid and valid states, and the error pages. Requests run in
# order against a fresh in-memory H2 database loaded from seed.sql (users admin, user1, user2 and a
# deleted one; domains /test, /library and a deleted /old; four PURLs with history). The UI is in
# German: the app's locale resolver defaults to German and ignores Accept-Language.
#
# The login form SHA-1s the password in the browser, so the posted password is the SHA-1 hex:
# admin = d033e22ae348aeb5660fc2140aec35850c4da997, user1 = b3daa77b4c04a9551b8781d03191fe098f325e67.
#
# Rows written through the UI are stamped with the current time, and only the PURL search and the
# info pages print timestamps; those pages are visited before anything is changed, and changed
# PURLs are not searched for or viewed afterwards. PURLs that redirect are never resolved (the
# target is an external site), and neither is the gone one: its message key is missing, so it is
# a 500 whose stack trace carries the controller's line numbers. Unknown ones show the 404 page.
#
# Unreachable: a valid domain create ("Domain created!") renders domaincreate.html without an
# `error` model attribute and the template crashes (a 500 with a Thymeleaf stack trace), so only
# its invalid states are requested.
#
# The domain and user modify forms disable the path and login inputs, so a browser never sends
# them and the app answers "Domain null existiert nicht" (domain) or silently does not save (user).
# Each form is posted once that way and once with the field added, to reach the saved state.
