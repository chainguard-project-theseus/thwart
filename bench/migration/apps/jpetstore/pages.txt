# jpetstore (Spring Boot 2.0 / Java 8 / Thymeleaf 3.0 + layout dialect + springsecurity4 extras):
# every template, anonymous and signed in, the cart, the whole order flow with each form invalid
# and valid, account create/update, and the error pages. Requests run in order against a fresh
# in-memory HSQLDB seeded by Flyway (users j2ee/j2ee and ACID/ACID, no orders).
#
# Order dates come from the clock and are ignored in app.json (no seeded order has a date).
