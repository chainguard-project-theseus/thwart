# posters-demo-store: the storefront (anonymous, guest checkout, a logged-in customer with an
# order) in two locales, and the backoffice (admin/admin-2026!, seeded by the app at startup):
# customers with their name, address and credit-card fragments, users, roles, the audit log and
# the module placeholders. Requests run in order against a fresh in-memory H2 database holding
# the app's catalog import and the ten demo customers from seed.sql (fixed ids
# 00000000-0000-4000-8000-0000000000NN, password topsecret).
#
# Not reachable from pages.txt: the DELETE endpoints (htmx hx-delete; the confirmation modals
# are fetched), the JSON APIs, and backoffice/admin/users/results.html (only for an HX-Request).
# A customer created in the backoffice gets a random UUID, so only the invalid create is posted.
# Adding a credit card in the backoffice fails in the app itself (Hibernate TransientPropertyValueException),
# so only its form is fetched. Sorting customers by name hits a Lucene error the app logs, so
# the list is sorted by number.
