# BudgetMaster (FreeMarker, held out): every template reachable without JavaScript or a file
# upload, anonymous and logged in, each form invalid and valid, and the error pages. Requests run
# in order against a fresh PostgreSQL database that holds only what the app creates at startup:
# the user "Default" (password BudgetMaster), the "All accounts" placeholder (account 1), the
# "Default Account" (2) and the categories "No Category" (1) and "Rest" (2), plus the built-in
# charts. start.sh pins the app's clock to 2025-06-15 10:00 UTC, so "today" and the current month
# are fixed; every date below is absolute.
#
# Not reachable here: the database import (importStepOne, importResult) and the bank CSV import
# rows (transactionImportRow) need a multipart file upload; the 403 page needs a POST without a
# CSRF token, which the app answers with 405.
