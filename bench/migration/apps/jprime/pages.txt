# jprime: every reachable JSP, anonymous and as admin, each form in its invalid and valid states
# where the form can be sent, and the error page. Requests run in order against a fresh in-memory
# H2 database loaded from seed.sql: the current branch is the 2099 conference (CFP open since 2020
# and until 2099-01-15, tickets on sale), plus a sold-out 2020 branch, speakers, submissions in
# every status, sessions, articles, tags, sponsors, partners, registrants and visitors.
#
# The app has no error status pages: errors redirect to /404, which answers 200.
#
# Not requested:
# - POSTs of multipart forms that need a file part (CFP proposal, admin speaker, sponsor, partner,
#   submission, visitor CSV upload): the recorder sends url-encoded forms, which these handlers
#   reject. Their pages are covered by GET.
# - tickets-result.jsp: buying a ticket needs the random captcha from /captcha-image.
# - Background jobs (send tickets, invoice e-mails): they run asynchronously with random IDs.
# - /admin/visitor/send's POST answers text/plain, not a page.
